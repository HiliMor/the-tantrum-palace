# Tantrum Palace

An interactive meltdown. A painting of a crying kid and a dripping dollhouse, rebuilt as ~230k GPU particles with three.js WebGPU compute.

- **Hover** to melt the palace
- **Hold** (mouse or space) to throw a tantrum
- **🍼 Pacifier** (or `P`) to drain the flood
- **🎤 Scream mode** — scream into your mic to feed the tantrum

Cry enough and the palace drowns in feelings. Rubber ducks included.

## Run

```sh
npm install
npm run dev
```

Needs a browser with WebGPU (falls back to WebGL2 with fewer particles).
